# Server Setup — Ansible Runbook Spec

Reproduce my macOS CLI environment on fresh Debian/Ubuntu VPS servers, repeatably,
via a push-style Ansible playbook run from the Mac. Verified locally against
Docker containers before ever touching a real VPS.

## Decisions (locked)

| # | Decision | Choice |
|---|----------|--------|
| 1 | Scope | Tooling + minimal baseline (apt essentials, admin user). No UFW/fail2ban/SSH hardening. |
| 2 | Dotfiles source | Vendored into this repo (`roles/*/files/`), fully self-contained. |
| 3 | Secrets | Zero secrets in repo. Server `.zshrc` sources optional `~/.zshrc.local`. |
| 4 | Install strategy | Hybrid: apt where good, pinned upstream binaries elsewhere, git clones for OMZ/p10k/plugins. |
| 5 | Architectures | amd64 + arm64 (arch-mapped release assets; arm64 tests via `docker --platform`). |
| 6 | User model | Create sudo admin user `sagar`; authorized_keys from `https://github.com/palsagar.keys` + optional local pubkeys. |
| 7 | Neovim | Pinned upstream binary + full vendored `~/.config/nvim` (LazyVim, no extras, lazy-lock.json included). |
| 8 | Python tools | `uv` official installer → `uv tool install thefuck ipdb`. |
| 9 | Docker | docker-ce + buildx + compose plugins from official repo; user in docker group. Binaries-only test (no daemon in containers). |
| 10 | Test matrix | debian:12, debian:13, ubuntu:22.04, ubuntu:24.04. |
| 11 | Test harness | Makefile + shell scripts; per-distro sshd test images; real SSH; verify play; idempotency re-run. |
| 12 | Execution | Push from Mac (`make provision HOST=...`). ansible-core installed via `uv tool`. |
| 13 | `.zshrc` | Standalone server fork, pruned of macOS-only lines; regenerated by `bin/vendor-dotfiles.sh` with explicit prune list. |
| 14 | Layout | Role-per-concern, tags for targeted re-runs. |

## Repo layout

```
server-setup/
├── SPEC.md
├── Makefile                  # setup / test / test-arm / provision / converge
├── ansible.cfg               # host_key_checking=accept-new, retry_files off
├── inventory.example.ini
├── group_vars/
│   └── all.yml               # server_user, github_user, ALL version pins
├── playbook.yml              # pre-task: raw python3 bootstrap; then roles
├── roles/
│   ├── baseline/             # apt update, essentials, locales, tzdata, sudo, ca-certs
│   ├── user/                 # admin user, ssh keys (github .keys + files/keys/*.pub), NOPASSWD sudo, chsh zsh
│   ├── shell/                # zsh, OMZ+p10k+plugins (pinned clones), vendored dotfiles, tpm + headless plugin install
│   │   └── files/            # zshrc (pruned fork), p10k.zsh, tmux.conf
│   ├── tools/                # fzf, eza, fd, bat, zoxide, yazi, lazygit, btop, tmux, uv, thefuck, ipdb
│   ├── nvim/                 # pinned neovim binary + vendored config + headless `Lazy! sync`
│   │   └── files/nvim/       # copy of ~/.config/nvim (incl. lazy-lock.json)
│   └── docker/               # official Docker apt repo, docker-ce + plugins, docker group
├── bin/
│   ├── vendor-dotfiles.sh    # Mac → repo copy with sed prune list
│   └── test.sh               # build images, run matrix, verify, teardown
└── tests/
    ├── Dockerfile.debian12
    ├── Dockerfile.debian13
    ├── Dockerfile.ubuntu2204
    ├── Dockerfile.ubuntu2404 # each: openssh-server, sudo, python3, test pubkey
    ├── verify.yml            # assertion play run against each container
    └── keys/                 # throwaway test keypair (gitignored private half is fine—test only)
```

## Per-tool install map

| Tool | Method | Notes |
|------|--------|-------|
| zsh, git, tmux, btop, curl, wget, unzip, tar, build-essential, dnsutils, locales, sudo, ca-certificates, gnupg | apt | `dig` comes from dnsutils (used in fzf ssh preview). |
| fd | apt `fd-find` | symlink `/usr/local/bin/fd → fdfind` |
| bat | apt `bat` | symlink `/usr/local/bin/bat → batcat` (Debian/Ubuntu naming clash) |
| fzf | GitHub release binary, pinned | must be ≥ 0.48 for `fzf --zsh` — apt is too old on all 4 targets |
| eza | GitHub release tarball, pinned | apt too old/missing on 3 of 4 targets |
| zoxide | GitHub release tarball, pinned | musl static builds available |
| yazi | GitHub release, pinned | verify glibc on ubuntu:22.04; fall back to musl build if needed |
| lazygit | GitHub release tarball, pinned | per-arch assets |
| uv | astral.sh installer, pinned via versioned URL | then `uv tool install thefuck ipdb`; pin `--python 3.12` (drop to 3.11 if thefuck breaks — tests will tell) |
| neovim | GitHub release tarball, pinned 0.11.x | per-arch assets; `nvim-linux-{x86_64,arm64}.tar.gz` |
| oh-my-zsh | git clone, pinned commit | set `zstyle ':omz:update' mode disabled` in server .zshrc |
| powerlevel10k | clone → `$ZSH_CUSTOM/themes/`, pinned commit | `.p10k.zsh` vendored as-is; Nerd Font is client-side (ghostty), server only needs `en_US.UTF-8` locale |
| zsh-autosuggestions, zsh-syntax-highlighting | clones → `$ZSH_CUSTOM/plugins/`, pinned commits | `web-search` plugin ships with OMZ |
| tpm + tmux plugins | clone tpm; run `~/.tmux/plugins/tpm/bin/install_plugins` headless | pulls vim-tmux-navigator, themepack, resurrect, continuum, which-key, yank from vendored .tmux.conf |
| docker-ce, containerd, buildx, compose plugin | official Docker apt repo | repo URL derived from `ansible_distribution` (debian/ubuntu) + arch |

Version pins live in `group_vars/all.yml` as `<tool>_version`; bump deliberately.

## `.zshrc` server fork — prune list (applied by `bin/vendor-dotfiles.sh`)

Remove: LM Studio PATH block, bun exports + completions, `claude-mem` alias,
`alias nvim="/opt/homebrew/bin/nvim"`, `OPENROUTER_API_KEY` export, duplicate
`gg`/`thefuck` lines. Add: OMZ auto-update disable + `[[ -f ~/.zshrc.local ]] && source ~/.zshrc.local`.

**Action item:** rotate the OpenRouter key — it has appeared in plaintext outside the machine.

## Testing

`make test` → for each of the 4 distro images:
1. `docker build` (sshd + sudo + python3 + throwaway key).
2. `docker run -d` with published SSH port; ephemeral inventory.
3. Run `playbook.yml` over real SSH as root → exactly the production path.
4. Run `tests/verify.yml`: every binary on PATH for user `sagar`, `zsh -i -c exit` clean,
   `tmux -V`, `nvim --version`, `docker --version` + `docker compose version`,
   dotfiles present, user shell = `/usr/bin/zsh`, tpm plugins cloned.
5. Re-run playbook → assert `changed=0` (idempotency).
6. Teardown. `make test-arm` repeats via `--platform linux/arm64` (QEMU, slower).

Known test limits: dockerd is not started in containers (decision 9); p10k glyphs
render client-side so visual prompt check happens on first real SSH session.

## Local prerequisites (Mac)

- `uv tool install ansible-core` (via `make setup`).
- Docker Desktop (already present).
- No other local deps — orchestration is Makefile + bash.

## Explicit non-goals

UFW/firewall, fail2ban, SSH hardening, swap, timezone config (beyond tzdata),
hostname, bun/node, claude-mem, LM Studio, dotfiles sync back to the Mac.
